# 评论判定与标注准则

本准则供评论治理演示和样本交接使用。判断对象是一条评论及其可见上下文；词语命中只是线索，最终标签必须能由原文证据支持。

## 一、标签与处置

当前网页每轮记录一个主风险标签，规则命中证据可以有多条。评论同时涉及多个风险时，主标签记录最需要处置的风险，其他风险写入判定理由；本版没有次标签多选字段。“语境待核”表示证据不足，不能替代已能确定的风险标签。

| 标签 | 判定依据 | 容易误判的边界 | 建议处置 |
|---|---|---|---|
| 身份攻击 | 因国籍、族裔、宗教、性别等群体身份贬低、排斥或煽动攻击个人及群体，包含仇恨歧视情形 | 批评某人的行为或政策，不自动构成身份攻击；转述歧视言论用于反对歧视，应结合立场判断 | 明确攻击拦截；对象或立场不清时复核 |
| 辱骂骚扰 | 对明确对象进行侮辱、持续纠缠、羞辱或围攻 | 方言、熟人玩笑、自嘲与一般负面评价不能仅凭单词判定；“这个方案很差”与攻击人格不同 | 明确、严重攻击拦截；轻度或关系不清时复核 |
| 暴力威胁 | 对现实对象表达伤害意图、号召施暴，或提供可识别的时间、地点等威胁线索 | 游戏战术、影视对白、夸张比喻与现实威胁分开；不能只看“杀”等词 | 可信、直接威胁拦截并优先复核；语境不清时复核 |
| 色情低俗 | 明确性招揽、露骨性描述、针对个人的性羞辱 | 医学、性教育、新闻或求助语境不自动视为违规；不得只凭人体词汇判定 | 明确招揽或攻击拦截；其他边界复核 |
| 隐私暴露 | 未经授权公布可关联自然人的联系方式、地址、证件、账号凭据等信息 | 号码外观不等于个人隐私；公开机构客服、自愿公开与虚构编号需分别判断；是否授权不明时不放大传播 | 明确泄露拦截；身份或授权不明时复核 |
| 诈骗引流 | 结合收益承诺、冒充身份、索取凭据、催促转账等证据诱导受害者转入私域或外部渠道 | 普通外链、正常商品咨询、反诈提醒不自动构成诈骗；不能把所有“联系我”都判成诈骗 | 明确诈骗拦截；仅有单一弱线索时复核 |
| 正常 | 当前文本及上下文未提供上述风险的充分证据 | 正常不等于赞同观点；尖锐批评仍可能正常 | 放行 |
| 语境待核 | 缺少必要上下文、语言无法可靠理解、对象或语气存在实质歧义 | 不得凭猜测补出身份、威胁意图或作者动机 | 人工复核 |

动作只有“放行、人工复核、拦截”三种。风险标签与动作分别记录：同一类风险因证据强弱、严重程度和语境差异，可以对应不同动作。规则引擎的风险分数用于排序，不表示校准后的违规概率。

## 二、先看语境，再判风险

按下列顺序阅读，不能跳过前两步直接套关键词。

1. **确认完整表达。** 阅读评论正文、父评论、视频主题与必要的会话片段；只使用样本实际提供的信息。
2. **确认说话立场和对象。** 区分本人主张、引述、反对、求助、讽刺与自嘲，确认攻击指向的是身份、个人行为还是虚构角色。
3. **定位证据。** 保存支持判断的最小原文片段，同时记录改变含义的否定、引号、转折或回应关系。
4. **判断标签和严重程度。** 选择证据充分的主风险；其他已识别风险写入理由，不以“最严重的猜测”代替证据。
5. **选择动作并写理由。** 理由应能说明“哪段话、为什么、采取什么动作”，不能只写“命中规则”。

| 场景 | 需要保留的信息 | 判定要点 |
|---|---|---|
| 引用攻击言论 | 引号、前后立场、被引用对象 | “有人这样骂他，这不应该”与作者主动攻击分别处理 |
| 反对攻击、反诈提醒 | 否定词、警示语、引用关系 | 不能因提醒中出现风险词而直接拦截 |
| 方言与熟人表达 | 语言、地区用法、双方关系证据 | 无法确认含义时复核；不能凭个人熟悉程度推断 |
| 跨语言、混合语言、谐音 | 原文、语言识别、规范化文本、映射方式 | 翻译或去符号可能改变含义；判定证据最终必须回到原文 |
| 隐私信息 | 信息类型、被指向对象、授权线索 | 只展示必要的脱敏片段；标注页和导出文件避免再次暴露完整敏感信息 |
| 威胁与诈骗 | 现实对象、行动意图、时间地点、转账或凭据要求 | 严重性和证据充分性分别判断，不以单一触发词下结论 |

对仅提供单条正文的样本，不能编造父评论或视频内容。发现缺少上下文会改变结论时，记录具体缺失项并转复核。

## 三、标注记录与交接字段

| 字段 | 当前演示 | 正式业务交接时补充 |
|---|---|---|
| 样本编号、数据批次 | 稳定编号，保留内置场景或本机导入来源 | 采集任务、授权范围与数据批次负责人 |
| 原文、语言、上下文 | 原文与中文释义分开，保留可见上下文 | 必要的父评论、视频证据及访问权限 |
| 风险、动作 | 单个主风险，动作独立记录；其他风险可写入理由 | 如需多标签，增加次标签及各自证据字段 |
| 证据与理由 | 规则命中可有多条；人工在文本理由中说明对象、行为及缺失信息 | 结构化证据片段、字符位置和缺失信息字段 |
| 标注轮次、时间 | 初审、复审、裁决分栏，操作历史保留；本机角色不等于经过认证的标注人 | 独立人员编号、权限、任务分配及审计记录 |
| 策略与规则版本 | 规则结果与人工意见分开；参数和策略版本随导出快照交接 | 在每轮人工任务中绑定当时的准则、策略及模型版本 |
| 分歧与裁决 | 对比两轮主风险和动作，保留原因分类与裁决 | 结构化分歧类型、准则变更编号和重标范围 |

本项目未运行模型，页面显示的是规则预测。导出时的当前策略不应被解释为每条历史人工意见产生时的策略版本；需要追溯时应一并保留对应快照。人工查看预测后再标注的样本，也不能与独立盲标样本混算一致率。

## 四、二审与分歧裁决

1. 初审完成主风险、动作和判定理由。当前页面辅助展示规则证据，初审不属于无预测提示的盲标。
2. 复审模式隐藏初审、规则预测和参考答案，要求重新阅读原文与上下文后判断；高风险、边界样本和新语言优先复审。
3. 对齐两轮结果。标签和动作分别比较；一致也不代表正确，需要抽查共同误判。
4. 仲裁查看双方证据和原文，给出最终结论。无法解决的准则空白交政策负责人确认，暂保留复核状态。
5. 修改初审后，原复审和裁决不再作为当前有效结论，需重新复审；修改复审后，原裁决失效。历史操作仍保留。
6. 将结论写入交接记录：新增边界例、受影响规则、是否需要重标及重评范围，策略变化另存快照。

这是本地协作流程演示，不代表已经组织真人标注团队。复审界面的隐藏只用于演示减少提示干扰；完整样本及参考答案在项目中公开，不能据此声称研究级盲法或严格隔离。演示参考标签来自项目自编样本：六种语言各12条，共72条，按固定编号分成48条策略样本和24条留出样本。参考动作为空的待核项不进入质量指标分母，仍计入样本总量和复核工作量。

## 五、交付检查

- 每条样本都有标签、动作和证据；正常样本也保留判定理由。
- 分歧样本都有处理状态，不能删除后只报告一致样本。
- 调规则只使用策略集，留出集用于冻结策略后的评价；后续增加同源改写时，应按样本族划分，防止相似文本跨集合泄漏。
- 分语言、风险类别和语境类型检查漏判与误判；单独列出“语境待核”和待复核数量。
- 如需报告一致性，说明样本数、抽样方式及是否独立标注；不能把规则与预设答案的一致率称为人工标注一致率。
