# 国际化评论治理工作台

一个面向评论风控、内容安全产品与运营岗位的中文作品集。把风险排查、样本标注、分歧处理、策略验证和算法交接放在同一个网页中。

## 打开网站

网页入口：`site/index.html`。全部网页资源随项目提供，不依赖外部CDN。

本机预览可在项目目录运行：

```bash
python3 -m http.server 8772 --bind 127.0.0.1 --directory site
```

随后打开 http://127.0.0.1:8772/ 。网页本身不需要安装前端依赖或模型。标注、导入和策略记录保存在当前浏览器，需要迁移时使用“导出工作记录”。

## 可以演示什么

1. 治理总览：按语言和周期查看样本、风险召回、正常误拦、人工复核与趋势。
2. 评论工作台：搜索评论，查看原文、释义、上下文和规则证据，分别保存人工判定。
3. 样本工作流：初审、复审、分歧与裁决；修改初审使旧复审失效；支持CSV/JSONL导入与结构化导出。
4. 策略实验室：调整阈值、语境和隐私设置，比较固定基线；冻结后再显示留出场景结果，保留版本快照。
5. 运营交付：指标口径、坏例归因、岗位流程、开源整合和面试演示。

内置72条项目编写场景，六种原文语言各12条，附中文释义；其中48条策略集、24条留出场景。未决标签与确定标签分开计数，零分母显示“—”。这些场景用于检查功能与规则边界，不能证明真实平台效果或开放场景泛化。

固定提交、官方来源与文件SHA-256见 `research/开源来源登记.json`、`docs/开源选型.md`。当前默认识别方式是可解释规则，0—100规则分不是模型概率。复审隐藏规则建议、初审与参考答案，但完整场景公开，不能把它描述成研究级盲隔离。

## 项目目录

```text
site/           可直接部署的中文静态网站
engine/         本地规则引擎和可选模型适配器
tests/          网页纯逻辑与规则测试
docs/           面试稿、判定准则、SOP和开源选型
research/       开源核验、来源与演示场景
third_party/    真实复用的第三方原件与许可
work/           本次核验记录，不作为公开网页上传
发布包/         网页发布包、完整源代码包
```

面试稿：`docs/岗位映射与面试介绍.md`及可编辑Word版`docs/岗位映射与面试介绍.docx`，包含30秒、90秒、3分钟介绍、常见追问，末尾列出15项需要掌握的细节及验证位置。
