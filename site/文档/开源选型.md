# 开源选型与集成边界

核验日期：2026年10月26日。本项目是中文求职作品集，围绕评论风险排查、样本标注、策略迭代与实验复盘组织功能。以下项目按岗位流程匹配选择，不按 star 排名。

## 选型结果

|---|---|---|---|

## 为什么这样整合

ECharts 可直接在静态网页展示筛选后的指标。Label Studio 的任务与标注结构适合作为向算法团队交付样本的接口；作品集保留轻量审核交互，不把完整标注平台搬进个人网页。Detoxify 用于说明未来模型分数如何接入规则与人工处置，当前演示不需要大型模型。

Evidently 提供数据质量、分类表现和监控窗口的组织思路。HateCheck 提醒我们按具体能力排查错误，例如引用、否定和反仇恨表达，避免只给一个总体准确率。Argilla 同样适合反馈回流，但其固定提交 README 已说明不再新增功能；本次保留为备选。

## 需要在面试中讲清的限制

- Detoxify 官方 multilingual 说明适用于英语、法语、西班牙语、意大利语、葡萄牙语、土耳其语、俄语。不能把中文或阿语演示包装成该模型已有验证的能力；上下文、反讽与群体指称也需要人工复核。
- HateCheck 官方套件包含 3,728 个用例、29 类功能测试，侧重英语仇恨言论。其覆盖范围不能替代垃圾营销、诈骗、骚扰等完整评论政策。
- 漂移、违规占比和策略效果是不同问题。观察窗口变化只能支持排查；没有随机实验或充分识别设计时，不声称策略造成了线上提升。
- 当前为作品集演示。展示样本、规则评分和离线指标应各自标明来源；未发生的真实平台流量、人工标注和线上实验不能写进项目业绩。
